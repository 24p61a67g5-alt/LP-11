Jenkins Build Performance Analyzer

Project Overview

The Jenkins Build Performance Analyzer is a web-based dashboard designed to monitor and analyze Jenkins build performance.

Features

- Displays Jenkins build status.
- Shows build duration.
- Visualizes build performance using charts.
- Identifies slow builds.
- Supports downloading build reports as CSV.

Technologies Used

- HTML
- CSS
- JavaScript
- Chart.js
- Python Flask
- Jenkins
- Git and GitHub

How to Run

1. Install Python and Jenkins.
2. Install the required Python packages: "pip install flask requests"
3. Configure Jenkins API access in "app.py".
4. Run the application using "python app.py".
5. Open "http://127.0.0.1:5000" in your browser.

Note

Configure Jenkins authentication securely before connecting the dashboard to live build data.
